Optional regular expression. If it matches the response body of an otherwise successful delivery, the delivery is treated as failed. Useful for receivers that report errors in the body of an HTTP 200 response. Leave empty to rely on the HTTP status alone.
Optional headers sent with every webhook: a name and a value each. Values can use tokens such as $result.host$; if one fills in a line break, the alert fails without sending. Values are saved with the alert in plain text, so put a secret in a credential instead.
